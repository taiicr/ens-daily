#1 Slice-Consistent 3D Volumetric Brain CT-to-MRI Translation with 2D Brownian Bridge Diffusion Model
它用 2D Brownian Bridge 擴散做出「切片之間一致」的 3D 轉換，直接對應你 2.5D 架構與 N=42 的小樣本痛點。Brownian Bridge 以來源影像為起點、目標影像為終點，很適合術前→術後的配對轉換。讀完你會得到跨切片一致性的兩個設計（SKC、ISTA），可作為 B 階段擴散選項（仍須先做回歸基線）。
🤔 這篇在解決什麼問題？
想像你要把一疊 100 張的相片「換風格」（例如 CT 變 MRI）。如果每張各自處理，相鄰兩張可能顏色、邊緣對不上，疊起來就會閃爍跳動。直接用 3D 方法一次處理整疊又太吃記憶體與資料。這篇用「逐張處理、但讓每張互相對齊」的方式，花小成本得到連貫的 3D 結果。
💡 看懂這篇你需要知道的名詞
Brownian Bridge Diffusion

一般 Diffusion 從純雜訊開始生成。Bridge 版本是「搭一座橋」：一端是輸入影像（術前）、另一端是目標影像（術後），模型學會沿著橋走過去，所以更適合「已有配對」的轉換。

切片一致性（slice consistency）

把 3D 影像看成一疊切片，相鄰切片的結構（如鼻腔壁）應該平順連續，不能忽大忽小。

2.5D

用 2D 網路處理，但把相鄰幾張切片一起當輸入，介於 2D 與 3D 之間，省記憶體。

🏗 他們怎麼做的？
① Style Key Conditioning（SKC）

像給每張切片同一把「風格鑰匙」，讓整疊切片的亮度與質感一致，不會張張不同。

② Inter-Slice Trajectory Alignment（ISTA）

生成時每張切片都在「走橋」，ISTA 讓它們走的路徑互相對齊，所以疊起來是連貫的 3D，而且結果可重現。

📊 結果如何？
摘要稱優於既有 2D 與 3D 基線，使用自有 CT-MRI 資料與 BraTS2023。本次只讀到摘要，沒有取得具體 PSNR/SSIM 數字，建議讀全文確認。
🔗 跟你的 ENS 研究有什麼關係？
B 階段若要用擴散，可把「術前 CT」當橋的起點、「術後 CT」當終點，並以 2.5D 切片式訓練省資料；ISTA 的概念可用來檢查預測的鼻腔壁、假體邊界在相鄰切片是否連貫（也可納入 D 階段評估）。不過 N 很小時回歸可能更準，請先做 Δ 直接回歸基線再比較。

Slice-Consistent 3D Volumetric Brain CT-to-MRI Translation with 2D Brownian Bridge Diffusion Model
Choo, Jun, Yun, Hwang · arXiv 2407.05059 · MICCAI 2024
BD
用 2D Brownian Bridge 擴散做切片一致的 3D 腦 CT→MRI 轉換，不需 3D 擴散的高成本。
▾
① 研究問題
只用 2D 擴散模型，能否做出「切片間一致」的 3D 影像對影像轉換（CT→MRI），避免昂貴且吃資料的 3D 擴散？
🏗 架構
2D Brownian Bridge 擴散（起點=來源影像、終點=目標影像，比一般從雜訊開始更適合配對 I2I）。加兩個模組：Style Key Conditioning（SKC）讓各切片風格一致；Inter-Slice Trajectory Alignment（ISTA）讓各切片的取樣軌跡對齊，使 3D 結果具確定性。
📊 訓練
資料：自有 CT-MRI 配對資料集與 BraTS2023 FLAIR→T1。細節（超參、GPU）本次僅讀到摘要，未驗證。
📈 結果
摘要稱優於既有 2D 與 3D 基線；本次僅讀到摘要，未取得 PSNR/SSIM 具體數字。
⚠ 限制
未能確認官方程式碼連結（摘要頁未列）；腦部 CT→MRI 為跨模態，與鼻腔術前→術後同模態差異大；細節需讀全文。
③ 可借用之處
B 階段：Brownian Bridge 以「術前 CT」為起點、「術後 CT」為終點，天然符合配對 I2I；2D 切片式＋跨切片一致性正好服務 2.5D 設計，解決小樣本 N=42 下 3D 擴散吃資料的問題。

Conditional Diffusion for 3D CT Volume Reconstruction from 2D X-rays (AXON)
Rath, Ghahremani, Li, Taghipour, Makowski, Wachinger · arXiv 2603.26509 · 2026
B
Brownian Bridge 粗重建＋ControlNet 精修的三階段條件式擴散，由 X 光生成 3D CT。
▾
① 研究問題
如何從 1–2 張 2D X 光重建高保真 3D CT？
🏗 架構
三階段由粗到細：(1) CoarseDiff：Brownian Bridge 擴散把 X 光升維成初始 3D 體積（3D U-Net，64 base channels）；(2) FineDiff：條件式 3D→3D 擴散＋ControlNet 精修細節；(3) ESRGAN 超解析 128³→256³。
📊 訓練
LIDC-IDRI 232 對真實 X 光-CT（197/10/25），另用 DeepDRR 生成 786 筆合成 DRR；Adam lr 1e-4；CoarseDiff 90 epochs、T=1000；ControlNet 微調 150 epochs；單張 A100、batch 2；重採樣 1mm³、HU [-100,900]。
📈 結果
LIDC-IDRI 單面/雙面 PSNR 21.21/21.71 dB、SSIM 0.540/0.576；較 X2CT-GAN 提升 PSNR 11.9%、SSIM 11.0%；內部 47 例外部驗證 PSNR 21.24。
⚠ 限制
解析度僅 128³（256³ 靠超解析）；僅胸部 CT；效能依賴 X 光與 CT 的配準品質；授權 CC BY-NC-SA 4.0（非商用）。
③ 可借用之處
「粗結構先出、ControlNet 再精修」的兩階段可類比：先預測 Δ 的粗略形態，再用手術條件精修；合成 DRR 擴充小樣本的想法可類比為對術前/術後 CT 做形變擴增。
